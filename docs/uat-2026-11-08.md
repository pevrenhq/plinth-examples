resource, or real infrastructure was changed. The approved applies below used

uses `validate -no-color`. Existing user edits remain preserved by bootstrap;
the three unchanged local example commands were updated explicitly.

ordering/locking were verified through application functions, not group-button
browser interaction. Mobile testing used viewport emulation, not a physical phone.
